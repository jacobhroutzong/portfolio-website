## Inventory and method

Scan the four curriculum JSON files, study page markup and scripts, and both Army Study documentation files for external HTTP(S) references. Collect source IDs, publication records, card IDs and reference fields before deduplicating by original URL. Include exact upstream downloads for cited edition blockers and checked candidates that may explain a correction. This preserves the evidence for former URLs after a link is replaced.

Use a redirect-following HTTPS GET with normal certificate validation. Record the last URL received, HTTP result, and the title, PDF cover, catalog record or change sheet when available. Check PDF identity independently of a successful HTTP response. Use existing same-edition verification where it is still applicable. An index result can confirm identity while direct access remains inconclusive. A login or logout page is evidence of an access gate. A timeout, TLS error, 403 or 429 alone is inconclusive. The status is relative to the expected resource in each row. A correctly identified legacy file is the wrong document when evaluated as a substitute for a current edition.
