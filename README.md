# Engineering portfolio

This repository builds the public portfolio and the approved research demonstrations. Commercial project pages are case studies. The production applications, scoring services, databases and their build pipelines are maintained separately.

Use Node 24, then run npm ci and npm run verify. For local navigation, use npm run dev. The Cloudflare Pages output is dist/. The only public Pages Function is the Harness² research proxy.

Before adding public files or a repository link, review data, licenses and generated assets, then update the corresponding allowlist. Never copy an app build into this repository. See docs/PUBLICATION.md.
